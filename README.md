# 🗺️ Jornada Mauá

### Software educacional gamificado para as aulas de Conexão e Desenvolvimento Profissional

**Projeto Integrador — Ciência da Computação | Instituto Mauá de Tecnologia**

Jornada Mauá é uma plataforma educacional gamificada desenvolvida em Java com integração ao banco de dados MySQL. O sistema utiliza a mecânica de um jogo de tabuleiro para apoiar as atividades da disciplina de Conexão e Desenvolvimento Profissional, tornando o acompanhamento das tarefas mais interativo e intuitivo.

No sistema, os alunos avançam por diferentes casas do tabuleiro conforme realizam atividades e questionários disponibilizados pelos professores. Além disso, podem acompanhar seu progresso, consultar notas e visualizar informações acadêmicas em um perfil personalizado.

Os professores possuem acesso a ferramentas administrativas que permitem gerenciar turmas, alunos, atividades e a estrutura completa do tabuleiro, possibilitando a personalização da experiência de aprendizagem e o acompanhamento do desempenho dos estudantes.

---

## 🎯 Objetivos

* Facilitar a organização das turmas para o controle do professor;
* Tornar o estudo mais dinâmico e interativo;
* Garantir controle e organização das tarefas criadas e realizadas;
* Centralizar o acompanhamento do desempenho dos alunos.

---

## 🚀 Como Executar

O projeto será disponibilizado através deste repositório contendo um arquivo executável, permitindo que o usuário utilize o sistema sem a necessidade de compilar o código-fonte.

---

## ⚙️ Funcionalidades

### 👨‍🏫 Área do Professor

* Login de professores;
* Acesso ao painel de controle administrativo;
* Gerenciamento de tarefas e questionários;
* Visualização das turmas cadastradas;
* Cadastro de novas turmas;
* Gerenciamento de alunos por turma;
* Acompanhamento do desempenho dos alunos;
* Visualização dos resultados das atividades realizadas;
* Administração do tabuleiro educacional;
* Adição de novas casas ao tabuleiro;
* Criação e organização de seções do tabuleiro;
* Visualização completa da estrutura do tabuleiro.

### 👨‍🎓 Área do Aluno

* Login de alunos;
* Acesso ao tabuleiro educacional;
* Navegação pelas casas do tabuleiro;
* Realização de atividades e questionários vinculados às casas;
* Visualização do perfil acadêmico;
* Consulta do RA e informações do curso;
* Acompanhamento da barra de progresso;
* Visualização do número de atividades concluídas;
* Consulta de notas e desempenho;
* Acompanhamento da evolução ao longo da disciplina.

---

## 🏗️ Estrutura do Sistema

### Front-end

Responsável pela interface gráfica desenvolvida em Java utilizando o GUI Builder do NetBeans.

### Back-end

Responsável pela lógica de negócio do sistema, utilizando Programação Orientada a Objetos.

### Banco de Dados

Responsável pelo armazenamento de usuários, questionários, respostas, progresso dos alunos e demais informações do sistema através do MySQL.
